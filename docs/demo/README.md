# Демонстрация основного сценария

Итоговое видео должно показывать настоящую production-версию с реальным
AI-провайдером, а не локальную заглушку.

- Production URL:
  `https://bbaqdcimsde8vli202gq.containers.yandexcloud.net/`
- Пример Excel: [`../../sample/sample_tasks.xlsx`](../../sample/sample_tasks.xlsx)
- Путь итогового видео: `docs/demo/ai-gantt-demo.mp4`
- Целевая длительность: 30–60 секунд.

## Сценарий записи

Перед записью откройте production URL в отдельном профиле браузера без
сохранённого плана либо нажмите «Восстановить демо-данные». Установите масштаб
браузера 100% и убедитесь, что в кадре нет персональных данных или облачной
консоли.

1. На 2–3 секунды покажите интерактивную диаграмму с готовым демонстрационным
   планом.
2. Через меню Excel выберите импорт и загрузите `sample/sample_tasks.xlsx`.
3. Выберите Replace, задайте дату начала `2026-09-07` и подтвердите импорт.
4. Покажите обновлённую диаграмму с параллельными ветками и связями задач.
5. Откройте AI-помощник и отправьте реальному Qwen команду:
   `Сдвинь все задачи Анны на 2 рабочих дня.`
6. Покажите единый предварительный просмотр затронутых задач и нажмите Apply.
7. Через меню Excel экспортируйте актуальный план и покажите, что браузер скачал
   `.xlsx`.

Если модель попросит уточнение из-за состояния после предыдущей попытки,
повторите Replace import и снова отправьте команду. Не подменяйте ответ модели
при монтаже. В финальном коротком ролике должны остаться непрерывная цепочка
«загрузка Excel → изменение через чат → экспорт» и видимое изменение диаграммы.

## Проверка перед публикацией

- Адрес в браузере соответствует production URL выше.
- AI-ответ получен от реального production-провайдера.
- В кадре нет API-ключей, `.env`, облачной консоли или локальных путей
  пользователя.
- Импортирован именно сохранённый в репозитории пример Excel в режиме Replace.
- Видны предварительный просмотр и результат Apply.
- Экспортированный файл действительно скачан.
- Видео сохранено по указанному пути и открывается после клонирования
  репозитория.

До добавления реальной записи этот пункт отмечается как `ТРЕБУЕТСЯ ЗАПИСЬ` в
матрице требований.
