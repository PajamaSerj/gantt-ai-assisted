# Демонстрация основного сценария

**Статус: ГОТОВО**

- Видео: [`ai-gantt-demo.mp4`](ai-gantt-demo.mp4)
- Production URL:
  `https://bbaqdcimsde8vli202gq.containers.yandexcloud.net/`
- Пример Excel: [`../../sample/sample_tasks.xlsx`](../../sample/sample_tasks.xlsx)

Финальная запись показывает настоящую production-версию с реальным AI-провайдером,
а не локальную заглушку.

## Сценарий, показанный в видео

1. Открыта production-версия с готовой интерактивной диаграммой.
2. Через меню Excel загружен `sample/sample_tasks.xlsx`.
3. Выбран режим Replace и задана дата начала `2026-09-07`.
4. Показана обновлённая диаграмма с импортированным планом.
5. В AI-помощник отправлена команда реальному Qwen на массовый перенос задач.
6. Показан предварительный просмотр затронутых задач и выполнен Apply.
7. Через меню Excel экспортирован актуальный план в `.xlsx`.

Видео подтверждает обязательную для тестового задания непрерывную цепочку
**«загрузка Excel → изменение через чат → экспорт»** и видимое изменение
диаграммы.

## Что проверено перед публикацией

- запись сделана на публичном production URL;
- AI-ответ получен от реального production-провайдера;
- в кадре нет API-ключей, `.env`, облачной консоли или локальных путей пользователя;
- используется сохранённый в репозитории пример Excel;
- показаны предварительный просмотр и результат применения изменения;
- экспортированный `.xlsx` действительно скачивается;
- итоговый файл сохранён в репозитории по пути `docs/demo/ai-gantt-demo.mp4`.

Сценарий можно повторить вручную по тем же шагам на публичном приложении.
